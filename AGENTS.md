# reqpipe — правила проекта

- `requirements-pipeline.html` — эталонная схема. **Не изменять.** Система строится по ней:
  дорожка = домен (`src/reqpipe/domains/<домен>`), карточка = элемент, стрелка = контракт `Consumes`.
- Домен импортирует из другого домена только `contracts.py`.
- После любых изменений: `python -m pytest` и `reqpipe check-reference` должны проходить.
- Запуск конвейера требований по идее пользователя — скилл `reqpipe-pipeline` (`.opencode/skills/`);
  выполнение одного этапа — скилл `reqpipe-stage`.
- Рабочая область прогона — `.reqpipe/`; вручную в ней меняются только файлы `results/*.json`.
